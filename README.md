# Trabalho em Grupo: Biblioteca C#
# Italo, Alcides, Eduarda, Guilherme e Letícia


Este projeto visa desenvolver habilidades de programação, particularmente por meio da implementação de algoritmos de busca e ordenação, utilizando um sistema de gerenciamento de bibliotecas como base prática.

Dentro do nosso código, implementamos e preferirmos selecionar Bubble Sort como um algoritmo de ordenação e Busca Binária como um algoritmo de busca principal, como o nosso programa possui uma lista ordenada, ou seja, a estrutura de dados não são desordenadas, a Busca Binária favorece a rapidez do processamento do código e obter
o resultado rapidamente, reduzindo o tempo de processamento e o custo de memória dentro da lista.
